# Business rules — Share ride

- Only the ride's customer can share, and only while the ride is active.
- Token: 192 random bits generated by the server; only its SHA-256 is stored;
  the ride id is never part of the link.
- Up to 10 live links per ride; "Stop sharing" revokes all of them.
- A link stops working at the earlier of `created + SHARE_RIDE_MAX_HOURS` and
  `ride end + SHARE_RIDE_GRACE_MINUTES` (checked on every read) → 410.
- The public view is read-only and sanitized: public status label, driver
  first name (and rating, if any), vehicle type / plate / description, pickup
  and destination, the driver's position only while the driver is committed
  to the ride, and timestamps. Never: the customer's identity, any phone
  number or email, the ride id or code, fares, payment, OTP, internal ids.
- No login, no caching, no search indexing; tokens are masked in access logs.
